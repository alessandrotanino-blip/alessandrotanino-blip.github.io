SQL Server Provisioning Portal

COMING SOON
SQL Server 2022 Always On / CAG IIS PowerShell Active Directory
Full details →

Enterprise self-service portal and orchestration engine for automatic database provisioning on SQL Server 2022 Contained Availability Groups over a Windows Server Failover Cluster (MSCS) environment. Users submit requests through a web portal on IIS, DBAs approve them with Windows SSO and a PowerShell engine runs the whole workflow end-to-end — creation/restore, backup, AG join and security — with zero manual work.

  • Self-service requests: new database or restore from .bak
  • DBA approval dashboard with Windows SSO and AD group check
  • Unattended PowerShell engine: create/restore, backup, AG join
  • Contained AG security: credentials replicated on every node
  • Auto-deploy script for Windows Server 2022/2025 + IIS

Key details

  • Targets: SQL Server 2022 Enterprise, Windows Server 2022/2025, IIS 10+
  • Full recovery model + full and log backups to a network share
  • Automatic replica synchronisation on the secondary node
  • CAG: SQL logins and Windows accounts created in the AG catalog
  • Email notification to the requester with connection parameters
  • Real-time request status tracking in the DBA dashboard

PKI Web Enrollment Portal

.NET 8 AD CS ACME / RFC 8555 Web Crypto REST API
Full details → Code on GitHub ↗

Modern ASP.NET Core 8 portal that replaces Microsoft's deprecated Web Enrollment (certsrv/ActiveX). Keys are generated directly in the browser, with native AD CS integration, approval workflows and a native ACME server (RFC 8555) for automatic renewals with win-acme, Certbot and Traefik.

  • Client-side key generation via Web Crypto (RSA / ECC)
  • Private keys encrypted at rest (DPAPI + AES-256-GCM)
  • Native ACME server (RFC 8555): win-acme, Certbot, Traefik
  • Template RBAC via Active Directory groups
  • Hold & review approval workflow with admin notes
  • 7 languages, light/dark themes, REST API

Key details

  • Runs on Windows Server + IIS, alongside Microsoft AD CS
  • Standalone mode (per forest) or multi-CA hub in the DMZ
  • COM CCertRequest integration with certreq.exe fallback
  • PKCS#12 (.pfx) package with user-chosen password
  • Built-in simulator for development and offline environments
  • Ownership check: certificates retrievable only by requester or admins

SSL/TLS Certificate Scanner

PowerShell SSL / TLS LDAPS Network Audit
Full details → Code on GitHub ↗

PowerShell scanner for SSL/TLS certificate auditing across single hosts, file-based lists, or entire CIDR network ranges. Multi-threaded scanning with HTTPS and LDAPS support, OS fingerprinting, reverse DNS, expiration filtering and automated reports.

  • Single site, bulk file and CIDR network range scans
  • HTTPS and LDAPS protocol support
  • OS fingerprinting and reverse DNS lookup
  • Expiration filtering for at-risk certificates
  • Multithreaded parallel processing
  • CSV export and automated email reports

Key details

  • Windows PowerShell 5.1 or PowerShell 7+
  • Custom ports and legacy SSL protocol versions
  • Per-scan tuning: thread count and timeouts
  • Built-in -Help and -Examples documentation
  • Append mode for incremental CSV exports
  • Custom DNS servers for reverse lookups
