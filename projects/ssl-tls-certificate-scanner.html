SSL/TLS Certificate Scanner

PowerShell SSL / TLS LDAPS Network Audit
Code on GitHub ↗

PowerShell scanner for SSL/TLS certificate auditing across single hosts, file-based lists, or entire CIDR network ranges. Multi-threaded scanning with HTTPS and LDAPS support, OS fingerprinting, reverse DNS, expiration filtering and automated reports.

  • Single site, bulk file and CIDR network range scans
  • HTTPS and LDAPS protocol support
  • OS fingerprinting and reverse DNS lookup
  • Expiration filtering for at-risk certificates
  • Multithreaded parallel processing
  • CSV export and automated email reports

Key details

  • Windows PowerShell 5.1 or PowerShell 7+
  • Custom ports and legacy SSL protocol versions
  • Per-scan tuning: thread count and timeouts
  • Built-in -Help and -Examples documentation
  • Append mode for incremental CSV exports
  • Custom DNS servers for reverse lookups
