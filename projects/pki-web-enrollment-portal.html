PKI Web Enrollment Portal

.NET 8 AD CS ACME / RFC 8555 Web Crypto REST API
Code on GitHub ↗

Modern ASP.NET Core 8 portal that replaces Microsoft's deprecated Web Enrollment (certsrv/ActiveX). Keys are generated directly in the browser, with native AD CS integration, approval workflows and a native ACME server (RFC 8555) for automatic renewals with win-acme, Certbot and Traefik.

  • Client-side key generation via Web Crypto (RSA / ECC)
  • Private keys encrypted at rest (DPAPI + AES-256-GCM)
  • Native ACME server (RFC 8555): win-acme, Certbot, Traefik
  • Template RBAC via Active Directory groups
  • Hold & review approval workflow with admin notes
  • 7 languages, light/dark themes, REST API

Key details

  • Runs on Windows Server + IIS, alongside Microsoft AD CS
  • Standalone mode (per forest) or multi-CA hub in the DMZ
  • COM CCertRequest integration with certreq.exe fallback
  • PKCS#12 (.pfx) package with user-chosen password
  • Built-in simulator for development and offline environments
  • Ownership check: certificates retrievable only by requester or admins
