HyperVisor Portal

PowerShell VMware vSphere Nutanix Proxmox VE IIS SQL Server

Enterprise multi-hypervisor inventory & reporting platform for VMware vSphere, Nutanix AHV and Proxmox VE. PowerShell agents periodically collect compute, memory, disk, network and backup metadata, publishing interactive HTML5 dashboards on IIS with full SQL Server history tracking.

  • Unified inventory across vSphere, Nutanix AHV and Proxmox VE
  • Project / cost center tracking via tags and categories
  • SQL Server history tracking with removed-VM search
  • Zombie VM, snapshot sprawl and backup compliance reports
  • Resource diff reports between any two dates
  • Automated IIS publishing with 7-Zip historical archival

Key details

  • PowerShell 5.1/7.x, PowerCLI 12+ and Prism Central v3 REST
  • IIS 10+ hosting with Production and Development environments
  • High-reliability LastSeenOn engine, no vCenter log dependency
  • 4-tier backup evaluation with custom retention thresholds
  • Live search, fast filters, column toggles and sorting in every view
  • Executive weekly, monthly and quarterly capacity dashboards
